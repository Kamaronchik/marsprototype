# Архитектура Mars Space (актуальная версия ТЗ)

Этот файл описывает проект таким, какой он есть сейчас. Он заменяет «Mars Space Architecture Plan» там, где они расходятся.

## Как устроено

- **Фронт:** React + Vite, Redux Toolkit, react-router, i18next (ru / uz / en). Папки: `src/pages`, `src/components`, `src/features`, `src/layouts`, `src/lib`.
- **Сервер:** Node + Express в `server/` (маршруты, контроллеры, `utils`). На Vercel работает как одна функция `api/index.js`.
- **База:** Supabase (Postgres). Миграции лежат в `supabase/migrations`, порядок и развёртывание описаны в README этой папки.
- **ИИ:** Google Gemini (репетитор для ученика, аналитика завуча). **Telegram-бот:** на сервере только через webhook, локально можно через polling (`npm run bot`).

### Правила безопасности

1. Браузер **не ходит в Supabase напрямую**. Он говорит только с нашим сервером.
2. Сервер работает с ключом `service_role`. На всех таблицах включён RLS и нет ни одной политики: закрыто для всех, кроме сервера.
3. Права проверяются на сервере: `requireRole(...)` в маршрутах и проверки владельца внутри контроллеров (учитель видит только свои группы, ученик только себя).
4. Прав отдельно от ролей нет: **роль = набор прав**. Экран, который роль не должна видеть, скрыт на фронте, но защищает только сервер.
5. Сессия хранится на сервере (cookie `httpOnly`). Новое устройство требует код 2FA из e-mail. Заблокированный или замороженный пользователь теряет доступ сразу.
6. Любые деньги и роли пишутся в журнал действий (`audit_log`).
7. Ключи только в `.env` (шаблон: `.env.example`). `.env` в `.gitignore`.

## Маршруты фронта

Названия маршрутов остаются прежними: `/admin`, `/academic`, `/teacher`, `/financier`, `/student`.
Чужая роль попадает на `/unauthorized`, неизвестный адрес ведёт на `/not-found`. Без входа ProtectedRoute отправляет на `/login`.

## Функции, которых не было в исходном ТЗ

- **Оценка уроков.** Раз в неделю ученик оценивает урок от 1 до 5. Учитель и завуч видят оценки без имён. Таблицы `lesson_ratings`, `lessons`.
- **ИИ-аналитика завуча.** Цифры считает код (посещаемость, оценки, риск). ИИ только объясняет их словами. Результат сохраняется в `ai_reports`, страница работает и без ИИ. Отчёт строится по кнопке и укладывается в лимит времени Vercel (запрос к Gemini ждёт максимум 20 секунд, у функции лимит 60).
- **Заморозка ученика.** Статус `frozen`: уроки не списываются, ученик не отмечается и не может войти. Разморозить может только админ.
- **Баланс ученика.** Админ пополняет баланс в сумах. История в `balance_transactions`.
- **Списание за урок.** Первая отметка ученика на уроке списывает цену урока (90 000 сум) один раз за запись посещаемости. «Опоздал» тоже считается присутствием.
- **Мультиязычность.** Русский, узбекский (латиница) и английский. Все тексты сайта и сообщения сервера переведены. Проверка: `npm run check-i18n`. Админ может менять тексты в настройках.
- **Коины и магазин, битвы, ИИ-репетитор, Telegram-бот** добавлены сверх ТЗ. Покупка защищена от двойного списания (тест `server/tests/shop.test.mjs`).
- **Предметы.** Одна группа = один предмет (`subjects`, `groups.subject_id`), названия на трёх языках.
- **Расходы и отчёты.** Категории: аренда, зарплаты, реклама, коммунальные, материалы, другое. Зарплаты учителей идут отдельной таблицей, категория «зарплаты» для прочих сотрудников.
- **Заявки кандидатов.** Публичный `POST /api/careers/apply` (лимит запросов, проверка файла по первым байтам, резюме в приватном bucket `resumes`). Сам сайт вакансий ещё не сделан.

## Тесты

`npm run test` запускает тесты прав и входа (`server/tests`). Они работают с настоящей базой и тестовыми аккаунтами `zz_test_*`
(`npm run seed-test-users`), пароли аккаунтов случайные и нигде не печатаются.
Тесты новых миграций пропускаются, пока миграция не применена.
